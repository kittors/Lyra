# ADR-0009：不引 turbo / nx

- 状态：已采纳
- 日期：2026-09-03

## 背景

六个包的 monorepo，通常这个规模就该上构建编排器了。

## 决定

不引。用 pnpm 的 `-r` 就够。

## 后果

依据是实测的数：

| | 耗时 |
| --- | --- |
| `pnpm lint` | 1 秒 |
| `pnpm typecheck` | 12 秒 |
| `pnpm test`（2086 条） | 25 秒 |
| `pnpm arch` | 2 秒 |

缓存能省下的时间少于多一层配置的成本——而那层配置有自己的失效模式（缓存命中了不该命中的、
任务图写错了导致顺序不对），排查起来比它省下的十几秒贵得多。

**什么时候重新考虑**：任何一项超过 60 秒。最可能先到那里的是 typecheck，因为 desktop 那个包
在长大。
