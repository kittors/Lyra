# ADR-0013：一个按钮组件，两种高度

- 状态：已采纳
- 日期：2026-09-03
- 相关：`packages/desktop/src/ui/primitives/Button.tsx`

## 背景

渲染进程里有 276 个手写的 `<button>`，高度至少八种：26、28、30、32、44。没有一个是有意与别人
不同的——它们只是分别被写下来的。一排控件不在同一条基线上，读起来像两个工具条被推到了一起。

`GhostButton` 与 `PrimaryButton` 早就存在，但在 `settings/controls.tsx` 里，而且已经被设置页
之外的地方引用。它们自己也曾经是 26 和 32，直到有人发现它们并排站在对话框脚下。

## 决定

`ui/primitives/Button.tsx`：四种变体（primary / ghost / subtle / danger）、两种高度（32 / 26）、
一个 loading 态。**不接受 `style` prop**——重点就是让调用方发明不出第九种高度。

旧的两个改成薄封装。在设置页里 `GhostButton` 仍然是对的说法，它们只是不再是「按钮长什么样」
的第二份定义。

## 后果

`loading` 是每个异步动作各自重造过的东西：有的把文字换成 spinner 于是整行跳一下，有的忘了禁用
于是能点两次发两次请求。现在宽度不变、`aria-busy` 会说、点击不穿透，测试逐条守着。

**没做的**：把那 276 处逐个换掉。新代码用 `Button`，旧的随手改。一次性替换会产生一个没人能审
的 diff，而收益是同一个。
