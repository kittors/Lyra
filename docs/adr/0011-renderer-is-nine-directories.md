# ADR-0011：渲染进程按域分九个目录

- 状态：已采纳
- 日期：2026-09-03
- 相关：`ARCHITECTURE.md`、`.dependency-cruiser.cjs`

## 背景

`src/` 下是 25 个散文件加一个装着 84 个文件的 `components/`。那 84 个里混着四类东西：谁都能用
的基础组件、认识「会话」和「分支」的业务视图、根本不是组件的纯函数、以及 hook。

后果不是难看，是**没有答案**。「dock 的代码在哪」只能搜；「这个新文件该放哪」没有依据，于是
继续往 `components/` 堆——那一层每个月都在长。

## 决定

九个顶层目录，各自回答一个问题：`app/` 窗口怎么装起来、`features/` 21 个用户看得见的域、
`ui/` 谁都能用的组件、`lib/` 纯逻辑、`services/` 跟主进程说话的唯一出口、`store/` 跨域状态、
`styles/`、`mobile/`、`assets/`。

**归属按依赖判断，不按名字。** 不引 React 且不碰主进程 → `lib/`；是组件但不读 store 不调
service → `ui/`；知道「会话」是什么 → `features/`。

## 后果

前两条由 `pnpm arch` 与 oxlint 强制，所以边界不会随时间模糊。规则第一次跑就抓到四处越界，
四处都是搬的时候「看起来很合理」的：`TimeAgo` 引了 git 域里的一个纯函数、`Toaster` 读 store、
`theme.ts` 调 services、`TypedText` 为了一个函数引了整个主题模块。

**代价**：296 个文件换了路径，`git log` 要加 `--follow` 才追得到早于这次的历史。用 `git mv`
做的，所以 `--follow` 是有效的。

**没做的**：每个 feature 一个 `index.ts` 作为唯一出口，以及据此禁止跨域深引。目录先立住，
出口是下一步——它要逐个域看清楚哪些是对外的。
