# ADR-0015：样式的三分法是检查，不是约定

- 状态：已采纳
- 日期：2026-09-03
- 相关：`stylelint.config.mjs`

## 背景

`styles.css` 拆成 22 个文件之后，「什么该写在哪」清楚了，「什么不该手写」还没有。

## 决定

stylelint 管三件事，每件都不是格式问题：

**颜色从 token 来。** 每个表面都读 CSS 变量，外观页才改得动它——「只暴露三个颜色，其余按对比度
滑块派生」只在没人自作主张时成立。一个手写的 hex 是一个不听用户选择的表面。

**过渡时长从三个 token 来。** 「减少动态效果」是靠把 `--ly-t-*` 归零实现的，所以一个手写的
`200ms` 不会跟着变短——它在别的元素都停下来的时候继续动。那是无障碍设置在一个元素上失效。

**类名是 `ly-`。** 其余是别人的：CodeMirror、xterm、KaTeX 都是靠覆盖它们自己发出的类名来改
样式的。

`animation` 故意不管：一个关键帧动画的周期是它本身的一部分（呼吸 2.4s、扫光 1.4s），那不是三档
刻度上的值。全局的 reduce-motion 规则会一次性压住它们。

## 后果

规则跑出来 45 处硬编码时长，10 处是真的漏改，全部换成了最接近的 token，差值都在 30ms 以内。

**调规则的过程里犯过两次错，都记在这里**：

一次是把类名正则放宽成 `|.*)$` —— 那让整条规则匹配一切，形同虚设。**一条不会失败的规则比没有
规则更糟，它读起来像是有覆盖。**

一次是 `--fix` 越权：它删掉了 `tokens.css` 里用来分组的空行，把「表面、分隔线、墨色、动效」四组
挤成一坨。分组是意思，不是格式。
