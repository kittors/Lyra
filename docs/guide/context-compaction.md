# 上下文压缩模型

「设置 → 智能体 → 会话」里的「压缩上下文」（即 `@compact` 角色）可以单独选一个模型，用来生成
主会话、子智能体和侧聊的上下文摘要。未配置或所选模型已不可用时，使用相应会话当前的模型。手动 `/compact` 同样使用
这个角色。

是否触发压缩、保留多少近期消息，仍由正在工作的模型的上下文窗口决定。摘要请求的输入预算和
输出上限使用摘要模型的限制。修改压缩模型不改变主会话或子智能体的回答模型。

摘要模型与当前模型不同时，请求副本会移除不可跨模型复用的推理签名和加密句柄。原始转录保持
不变，后续仍可通过历史与 `recall` 查看。宿主替换模型请求时，摘要也通过同一请求适配器，携带
实际摘要模型与供应商。
