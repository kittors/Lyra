# 生成图片

对话里说「画一张……」「把这张图改成……」，模型会调用 `image_generate`，用你配置的生图模型把图画出来，
直接显示在对话里。画的过程中，图的位置先是一块按目标比例排好的点阵，上方一行写着进行到哪一步，
右下角是进度；图到了就在原地显出来，下面的内容不会跳。

## 加一个生图模型

设置 → 模型设置 → 选供应商 → 添加模型，填模型 ID，例如：

- `gpt-image-1`、`gpt-image-2.5`（OpenAI 及兼容的中转）
- `gemini-3.1-flash-image`、`gemini-2.5-flash-image`、`gemini-3-pro-image-preview`
- `dall-e-3`、`imagen-4.0-generate-001`、`flux-1.1-pro`、`doubao-seedream-4-0`

名字认得出的会自动打开「生图模型」开关；自家起的名字（比如 `house-artist`）自己打开就行。
生图模型不会出现在对话模型的列表里。

很多中转的 `/v1/models` 只列聊天模型，所以「拉取模型」里通常看不到生图模型，要手动加一次。

加完点模型那一行的测试按钮，会真画一张小图（会计费），能用就会显示画出来的尺寸。

## 用哪一个

有一个就用那一个。有好几个时，在 设置 → 智能体 → 会话 → 生图模型 里选默认的；不选就是第一个。
对话里点名也行：「用 gpt-image-2.5 画」。

## 改图

把图贴进输入框，说要改什么。模型用 `#1` 指对话里最新的一张图（你贴的，或者上一次画出来的），
`#2` 是再往前一张。画出来的图悬停时有「编辑」：在大图上标出要改的地方，保存后标注图会放进输入框，
接着说明要怎么改即可。

## 比例与清晰度

说「16:9 横图」「竖版手机壁纸」「正方形头像」就行，模型会选比例。要更清晰就说「高清」或「4K」——
Gemini 的 4K 图有好几 MB，经中转下载会慢不少。

## 出错时

- **额度用完**：卡片上直接写「额度用完了 · 约 1h 53m 后恢复」，不会重试。
- **这个密钥不能使用某模型**（403 `model_not_allowed`）：中转按渠道分组限制了这把密钥。到中转后台给
  密钥开放这个模型，或者把供应商地址换成包含它的分组路径，例如 `https://你的中转/group1`。
- 网络抖动最多再试两次；画图是一次计费的调用，等不到就报出来，而不是一直转圈。

画出来的图存在 `~/.lyra/session-media/`。设计取舍见 [ADR-0033](../adr/0033-drawing-is-a-tool.md)。
