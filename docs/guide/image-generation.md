# 生成图片和视频

对话里说「画一张……」「把这张图改成……」，模型会调用 `image_generate`，用你配置的生图模型把图画出来，
直接显示在对话里；说「做一段……的视频」「让这张图动起来」，就是 `video_generate` 和视频模型。没配对应的
模型时，模型手里没有那个工具。画的过程中，图的位置先是一块按目标比例排好的点阵，上方一行写着进行到哪一步，
右下角是进度；图到了就在原地显出来，下面的内容不会跳。视频同样占位，上方写着在排队、在生成还是在取回，以及
已经等了多久。

## 加一个生图或视频模型

设置 → 模型设置 → 选供应商 → 添加模型，填模型 ID，例如：

- 生图：`gpt-image-1`、`gpt-image-2.5`、`gemini-3.1-flash-image`、`grok-imagine-image`、`doubao-seedream-4-0`
- 视频：`grok-imagine-video-1.5`、`doubao-seedance-2-5-260628`、`veo-3.1-generate-preview`、`wan2.7-t2v`、
  `kling-v2-master`

名字认得出的会自动把「用途」设成生图或视频；自家起的名字（比如 `house-artist`）在模型编辑器里自己选。生图和
视频模型都不会出现在对话模型的列表里。

视频模型还有一项「视频接口」，默认自动：

| 选项 | 是谁的 | 典型地址 |
| --- | --- | --- |
| xAI | grok-imagine-video，以及照搬它的中转（CliRelay） | `https://api.x.ai/v1` 或中转地址 |
| 火山方舟 | Seedance（豆包），以及照搬方舟路径的中转 | `https://ark.cn-beijing.volces.com/api/v3` |
| OpenAI 视频格式 | new-api 等中转统一接的可灵、万相、即梦、Vidu | 中转地址 |
| Google Veo | Gemini API 的 Veo | `https://generativelanguage.googleapis.com/v1beta/openai` 也行 |
| 阿里百炼 | 万相（DashScope 原生） | `https://dashscope.aliyuncs.com/compatible-mode/v1` 也行 |

自动的意思是：先看地址（官方地址一看就知道），再看模型名，再试中转常见的格式；只有「这个接口不存在」时才换
下一种，并记住走通的那种。别的报错不换——第二个被接受的任务就是第二份钱。

「拉取模型」能列出生图和视频模型的中转，勾上就加进来了。很多中转的 `/v1/models` 只列聊天模型，这时在拉取弹窗的
搜索框里敲模型 ID、按回车，一样能加。

加完点模型那一行的测试按钮：生图模型会真画一张小图，视频模型会真做一段最短、最低清晰度的视频（都会计费），
能用就显示出来的尺寸。

## 用哪一个

从具体到兜底，四层：

1. **这一次点名**：「用 grok-imagine-image 画」，或者在消息里 `@grok-imagine-image`（打 `@` 时候选里有「生图与
   视频模型」一组）。
2. **这个对话**：输入框底部魔法棒那个小图标——配了两个以上生图或视频模型时才出现。悬停能看到这个对话现在
   用谁画、用谁做视频；点开分生图、视频两节，选一个就只改这个对话。这个对话单独选过时，图标是蓝色的。
3. **默认**：设置 → 智能体 → 会话里的「生图模型」「视频模型」，或者在供应商的模型列表里点「设为默认生图/视频
   模型」。输入框的菜单里也有「设为默认」。
4. **自动**：哪个都没设，就用列表里第一个，模型列表上那一行标着「默认（自动）」。

点名和 @ 不只管一张：画成了，这个对话就改用它，接着说「再暖一点」还是它。一次点了两个模型（「两个模型各画
一张比一比」）不算选择，对话原来用谁还是谁。子智能体画图时跟着它所在的对话走，它自己点的名不会改对话。

换了之后，下一张就用新的——它正连着画好几张时也一样；正在画的那张照原来的画完。

两个供应商有同一个模型时，名字后面会带上供应商，比如 `gpt-image-1 (中转 A)`，点名照这样写就能点准。

对话里选的那个模型后来被删了、或者供应商停用了，就退回默认，输入框的菜单里会说一句「之前选的已经不在了」。

## 改图、重画、做成视频

把图贴进输入框，说要改什么。模型用 `#1` 指对话里最新的一张图（你贴的，或者上一次画出来的），
`#2` 是再往前一张。画出来的图悬停时有：

- 「编辑」：在大图上圈出要改的地方，按「完成」后标注图会放进这个对话的输入框，接着说要怎么改就行。
- 「再生成」：换一个生图模型照原提示词和参考图重画，或者选一个视频模型把这张图做成视频。选完就发出去
  （输入框里有你没发的字时只填进去，不替你发），对话也随之改用那个模型。
- 「下载」：存的是原文件，名字是 `lyra-image-年-月-日-时-分-秒`。

视频悬停时有「下载」（`lyra-video-…`）和「换个视频模型重做」。

## 看视频

对话里、创作里、文件面板里的视频都用 Lyra 自己的播放器：暂停时中间一个播放键，底下一条控制条（播放、时间、
进度条、声音、全屏、更多），播放时鼠标不动一会儿控制条自己让开，一动就回来。点一下画面也会获得键盘：空格或 K
播放暂停，← → 退后/前进 5 秒，M 静音，F 全屏。

- **全屏**（控制条上的按钮、F 或双击画面）：只铺满 Lyra 这个窗口，盖住侧栏和面板，窗口本身不动，也不会切到
  系统全屏；视频接着播，不会从头开始。Esc 或再按一次按钮退回原处。铺满时按键都归播放器——在创作里 ← → 是快进
  快退，不会换到别的作品，Esc 只退出全屏，详情页还开着。
- **屏幕全屏**（控制条最右边的「更多」里）：真的占满整块屏幕。Esc 退出，回到你进屏幕全屏之前的那一档——从铺满
  窗口进来的就回到铺满窗口。

## 比例、清晰度、时长

说「16:9 横图」「竖版手机壁纸」「正方形头像」就行，模型会选比例。要更清晰就说「高清」或「4K」——
Gemini 的 4K 图有好几 MB，经中转下载会慢不少。视频还能说时长、清晰度（480p/720p/1080p）和要不要声音。

各家能接受的不一样：Veo 只有 16:9 和 9:16、4/6/8 秒，1080p 只能 8 秒；Seedance 2.5 是 4–30 秒；有首帧时
比例跟着首帧图走。做不到的会改成最接近的，结果里如实说。图也一样：比例没照做、要了透明背景却不透明，模型会
告诉你。

## 出错时

- **额度用完**：卡片上直接写「gemini-3.1-flash-image 的额度用完了 · 约 1h 53m 后恢复」，不会重试。
- **这个密钥不能使用某模型**（403 `model_not_allowed`）：中转按渠道分组限制了这把密钥。到中转后台给
  密钥开放这个模型，或者把供应商地址换成包含它的分组路径，例如 `https://你的中转/group1`。
- **内容被拒**：说清楚是被拒了，同样的请求再发也会被拒。
- **视频任务找不到了**：任务过期，或者中转重启过；再生成一次。
- **视频等太久**：20 分钟还没好就不再等了，服务商那边可能还会生成完，任务没有取消。
- **按了停止**：只是不再等；视频这种已经提交的任务，服务商那边可能已经计费。
- 网络抖动最多再试两次；视频轮询时偶尔一两次查询失败不算失败。

## 创作

图标栏「插件」下面是「创作」（以前叫画廊）：所有对话里画过的图和做过的视频按天排在一起，宽图按原比例排，不裁成
方块；视频显示第一帧，右上角标着时长。卡片左上角的数字是这件作品所在的那条链一共几步，悬停能看到当时说的那句话。
顶上的搜索框按说过的话、提示词和对话名找。

点开一件：

- 右边是它的生成链路：从第一张起，一步步改到现在的样子，每一步写的是你当时说的话；图做成的视频也接在链上。同一张
  图往两个方向改过，另一条分支整段列在后面，左边一条括线接回它是从哪张分出来的；这一件自己的来路用蓝色标出。旧
  对话没记下每次改的是哪张，按当时的 `#1`、`#2` 倒推出来。
- 「在对话中查看」打开那个对话，滚到画出它的地方，框闪一下。
- 图片下面的输入框写一句要怎么改，回车就发到这张图所在的对话，图一起带过去；画好以后回到创作，直接停在
  新图上。左边的笔可以先在图上圈出要改的地方，圈过的那一步也会出现在链路里。视频直接在这里播放。
- ← → 换上一件、下一件，Esc 关闭，点大图可以放大。

创作里不显示会话列表。要用的话点左上角的侧栏按钮，只在这一趟里打开。

## 现在还做不到

- 手机上看不到画出来的图和视频，也没有创作。
- 子智能体画的图在它自己的面板里，不在主对话里，也不进创作。
- 改视频、续写视频；可灵、MiniMax 官方直连（经中转可以）。
- Lyra 退出时正在等的视频任务，下次打开不会接着等。
- 画图和视频的花费不计入用量统计。
