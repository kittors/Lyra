# 视图切换与加载

`RetainedViews` 用 React `Activity` 保留访问过的视图。隐藏时暂停 effect，再次显示时恢复；
保留的本地状态不等于仍在运行的请求。Git 子视图由仓库路径 `cwd` 隔离，不能跨仓库复用结果。

`Collapse` 在关闭动画结束后释放过程正文；关闭途中切换页面时，`Activity` 隐藏会取消 CSS
transition，生命周期清理也必须释放这份临时正文，不能一直等待不会到来的 `transitionend`。
仍展开的内容以及明确设置 `keepMounted` 的正文保留原有 DOM，返回时继续显示。

切换项目在显示新草稿时完整缓存旧会话并清理旧轮次状态，然后保存项目最近访问记录。
保存完成不能再次重置会话；较新的项目或会话选择使旧目录查询失效，后续页面选择也不能被
后台保存抢回聊天页。

## 流水线

流水线列表的 `null` 表示尚未取得结果，`[]` 表示已确认没有记录。缓存读取同样区分这两种状态，
空数组也是有效缓存。

- 首次读取尚未返回时，只允许显示加载容器；超过 `useSlowLoad` 的阈值后显示骨架屏。
- 已有结果（包括空结果）刷新时保持内容，右上角刷新图标表示请求正在进行。
- 隐藏或卸载视图后，旧请求失去写入显示状态与缓存的资格；恢复后的请求负责下一次更新。
- 同一次可见期间只运行一个列表请求，轮询不能不断淘汰尚未完成的慢请求。
- 更新列表长度不触发额外的首次请求。刷新失败保留已有结果并显示错误，不能伪装成空列表。

空状态用图标和简短状态表达结果，刷新和发版入口使用右侧图标按钮；工具提示和无障碍名称
保留完整操作含义。说明性长文不放在空面板中央。

组件回归覆盖首次读取、空缓存、Activity 恢复、乱序响应与慢请求；Electron E2E 从可见 DOM
逐帧采样，区分当前视图与仍保留在 DOM 中的隐藏视图。
