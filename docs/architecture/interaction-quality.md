## 会话稳定性与性能

会话布局采用与拖放落地的冻结优先于“减少动态效果”。后者保留 `0.01ms` 过渡以发送结束事件，
但不能把前者明确关闭的过渡重新打开，否则新面板会短暂透明，固定定位切回绝对定位时也会跳位。
拖放位移的清理与定位方式切换在同一次布局提交完成，不能在 `transitionend` 中提前清空位移。
`dock-settle` 在应用动画开、关两档下逐帧检查透明度，并独立检查位置与宽度到达后不再偏离，
避免尺寸尚未到达时漏掉位置已经到达又跳走的情况。

已有的分裂思考行 key、按需挂载和跟随滚动修复继续保留。真实回归验证重复切换不会累积孤立节点，
在同一份转录中滚动不会改变滚动条范围，展开状态和阅读位置会恢复，热缓存从首个绘制帧保持稳定。

本轮将后台会话事件折叠进已读缓存，避免每次后台消息都清掉缓存；冷读保留磁盘历史与读取期间的事件，
热读不能覆盖期间到达的新内容。会话缓存和展示状态分别限制为 12 份。页面 Activity 保留访问过的少量
分区，隐藏时暂停 effects；不是为每个会话保留完整隐藏 DOM。

问题导航的当前窗口内滚动统一为 420ms。跨历史窗口先挂载后定位，首帧不播放跨越未挂载内容的长距离滚动。
导航预览实测为 360×57px。刻度与侧栏缩放命中区错开，窄刻度轨道不叠加抢点击的滚动条。

独立慢 MCP 完成路径验证：创建后离开会话，后台仅生成一次回复；回访连续 20 帧都包含完整回复。
日志中只有一条 user 与一条 assistant，pendingPrompt 已清除。自动 worktree 改变执行路径，保留原会话 ID、
projectId 和初始化期间用户设置的标题。

## 自动 Skill 的真实环境结论

检查了用户环境中的两个既有候选，没有修改或启用它们：

- `release-version.md` 固定“6 个 package.json”和旧路径，把强制 Release dry run 降为推荐，固化旧发布操作。
- `dual-repo-release-sync.md` 绑定两个具体仓库的协作关系，应声明项目适用范围，不能当成跨项目通用流程。

进一步使用用户当前配置的 `@fast` 模型，从 37 份符合条件的真实会话中选择 4 份发布相关历史，进行
无工具调用的提案验证。第一次仅加强提示词仍生成了遗漏当前 AGENTS、手动 add/tag/push 的提案，
因此没有把“格式合格”当作语义合格。

修正输入链路后，生成过程读取当前项目指令。第二次真实生成耗时约 16.3 秒，结果为
`lyra-project-release`、scope=project，引用两个真实来源；要求每次重读 AGENTS，保留
`pnpm release:rehearse` 强制门禁，调用 `pnpm release`，禁止手工发布旁路、忽略检查和擅自回滚。
它不再固定包数量或当前版本。由于证据属于 Lyra 的专有发布流程，明确项目范围是正确结论。

portable 候选必须通过输入发现当前仓库的脚本、版本策略和约束；不能通过删掉可执行细节来伪装通用。
自动检查能约束结构、来源和记录格式，不能证明任意模型输出的语义都正确，候选仍需人审阅后启用。
本次真实生成结果只保存于临时验证目录；用户真实候选、MEMORY.md 和启用列表均未改动。

## 第 16 项：斜杠命令输入与执行

手动压缩原来只绕过自动触发阈值，近期消息保留预算仍按整个模型窗口计算。大窗口下，全部历史
都落在保留预算内，代码在发起摘要请求前就返回了“已经够紧凑”。新增回归先确认摘要请求数为
0，再将手动保留预算改为同时受当前会话大小约束。自动压缩继续使用原有阈值和失败降级行为。

`/compact` 可以无参数执行；后面的文字通过 IPC 传给摘要模型，作为需要保留内容的要求。
执行期间有持久命令记录和进度，完成、无需压缩、失败和取消都有明确结果。空摘要、连接失败或
取消不会替换原上下文。运行中的重复压缩复用同一次任务，后续消息等待边界落定后执行。
切到其他会话可以继续发送，状态按会话 ID 和命令 UUID 隔离；回退历史、热缓存、冷读取与重启
回放都携带相应记录。重启不会自动重试未完成的压缩。完整原始转录始终保留，命令记录不作为
模型的普通用户消息，也不占据用户问题导航刻度。

输入仍由原生 textarea 负责。已识别的行首命令使用行内代码样式，参数提示只在不参与选择和
复制的装饰层中显示；普通提示词、路径、参数、换行和 emoji 保持原始文本。菜单点击和 Tab
只补全，完整命令和唯一匹配的命名空间简称可直接 Enter 发送；Shift+Enter 与中文组合输入
保留原生语义。自定义命令发送时重新读盘，展开当前定义和参数；扫描期间已修改或切换的草稿
不会被旧结果清空或误发。`/clear` 新开空白会话，`/commands` 打开命令设置。

菜单与输入框同宽，包含图标、名称、同行描述、来源和分组；长文本使用 `ScrollText`，上下
溢出使用 `Scroller`。方向键选择会揭示对应条目，列表只滚动自身。收起期间保留原来的分组和
选中位置，同时移除交互与无障碍选项，避免淡出时改排版。减少动画设置同时约束菜单和文字滚动。

真实 Electron 验证还发现并修复了两个输入细节：末尾换行在装饰层少占一行，与 textarea 相差
23px；超长参数提示会换到被裁掉的下一行。现在末尾空行高度一致，提示留在当前行并在右边界渐隐。

### 根因与实现约束

压缩占比原来通过完整日志 `messages` 计算；日志为了回看而保留原文，模型则使用摘要与尾部。
回归红测中压缩前后均为 12956 tokens。现在 `contextBreakdown()` 直接用 `modelHistory()`，
前端也使用同一个会话范围内的统计结果，避免自行重算原始转录。后台生成期间，关闭的用量面板
只在回合/压缩边界刷新，不在每条工具消息后重建提示词。IPC 失败有明确提示，不无限显示加载。

另一个边界是摘要重建时的时间戳：若每次读取都写当前时间，会把压缩后刚收到的实测用量也误判
为过期。压缩事件的持久时间作为边界，冷恢复后读数保持一致；新增回归验证后续响应的
20300 tokens 被连续两次读取正确识别为 measured。

项目记忆沿用已有的 `learned.md` 和后台提炼的 `MEMORY.md`，保留去重、数量限制、脱敏与
“记忆冲突时以当前代码为准”的规则，不另建一套存储。自动沉淀需开启对应开关，空闲 5 分钟后
筛选 12 小时至 30 天内会话，每天最多一次，通过用户配置的模型提炼。查看用量不会写入
“最近注入”时间。未设置新项目开关的老配置继承原记忆开关的有效值；应用启动不再悄悄开启
自动提炼。设置中的开关可以分别控制个人偏好与项目经验，自动提炼还受项目开关约束。

## 智能体运行配置与侧聊历史

### 子智能体

“设置 → 智能体”的每个有效定义右侧提供供应商/模型与思考等级选择。配置存入
`subAgentProfiles[agentName]`，具体模型使用包含供应商的本地 id，同名上游模型不混淆。
优先级是本机单独配置、定义中的模型引用/角色、派发会话的模型；思考等级依次取单独配置、
已解析定义的后缀、全局默认，并按实际模型能力显示和执行。切换模型时清除旧等级，非推理模型
不提供无效档位。明确指定的供应商被禁用或模型被删除时，显示失效状态并拒绝派发，不悄悄换用
另一供应商。恢复继承删除该智能体的本地覆盖。

`fast`、`deep` 与已有 `review` 都是真实内置定义，设置目录、`@` 选择和 `task` 派发读取同一目录。
旧 `modelRoles` 与只含思考等级的 `subAgentProfiles` 按字段合并读取；保存或清空同名配置时删除
对应旧角色字段，避免清空后旧模型复活。`compact` 只提供压缩模型选择，`@compact` 与 `/compact`
共用内置压缩执行链，并保留附加指令；它不注册成可由 `task` 派发的普通智能体。

每次派发读取最新设置，递归派发沿用同一读取入口；已经开始的模型请求继续使用原配置。
定义里的 `minimal`、`xhigh`、`max`、`ultra` 后缀也能解析并传给实际请求。
配置通过主进程保存并通知活动会话，磁盘保存失败时保留原配置并显示错误。

### 侧聊

原实现有三处直接漏读：`restore([])` 也把主历史计数设为已同步；用消息数量判断同步忽略同长度
编辑与主历史回退；工具结果只保留前 400 字符。另有持久化时机错误：`message_end` 广播和写盘
发生在最终回答加入数组之前。旧版隐藏的主历史注入消息还会让 UI 的编辑索引与运行时不一致。

现在每次侧聊提问获取当前主会话的一份一致记录，近期快照有大小预算，不冒充全量历史。
`read_main_chat` 从这份完整原始记录按消息、字符偏移、关键词分页查询；完整工具参数、工具
输出和可见思考文字均可读取，图片按 content 索引返回给支持图片的模型。工具绑定当前主会话，
不接受其他会话 id 或文件路径。主聊天压缩只改变模型上下文，原记录继续可查。

侧聊自己的长历史使用已有压缩机制，并在连续追问间复用压缩结果；原始问答仍完整保存。
主历史快照每次更新，不写入侧聊持久历史；冷恢复过滤旧隐藏快照，让编辑索引重新一致。
最终消息先进入运行时状态，再发出完成事件和写盘。同一文件的保存/清空排队执行，并在调用时
序列化快照，避免共用临时文件、写入乱序或清空后旧数据复活。保存失败有日志和可见提示。

切换时先显示缓存，再按快照 revision 重放更新的流式事件；后台事件只更新所属会话缓存，
A → B → A 的迟到读取不能覆盖新的 A。冷打开只读取侧聊文件，不为每次侧栏导航启动并固定
一个主会话运行时。首个提问初始化使用同一个 Promise，运行锁早于异步广播，reset 隔离旧回调。

侧聊模型优先使用当前窗口明确选择，其次是创建侧聊时保存的默认选择；`null` 表示每次请求开始时
跟随主会话。全局默认仅作用于新侧聊和重开，已有选择不会被设置变化覆盖。模型选择与清空写入同一
持久化队列，写盘成功后才发出带 `sideRevision` 的 `side_model` 事件。消息保存只更新历史，不覆盖
已提交的模型选择。保存失败保留原状态，等待这次选择的提问会报告失败；等待阶段也可停止请求。
跨供应商、API 或上游模型切换时，每次请求移除不匹配历史中的推理签名和加密句柄，保留文字及
完整原记录；恢复存档和跟随主会话的切换同样经过此处理。

## 浏览器菜单与 Agent 光标

浏览器单标签和空状态保留一条 40px 导航栏，次要操作使用现有 Popover/Menu 组件。
多个标签显示标签行；视口预设、尺寸输入和书签列表在同一菜单内切换，避免堆叠工具栏。

旧光标注入网页 DOM，普通点击下存在节点，但原生 dialog 的 top layer 会遮住它，导航会销毁它，
只执行滚动也不会创建它。`browser-actions` 现在只定位可见元素并派发原生输入；主进程把操作坐标写入
所属标签的 `BrowserPointer`，经既有 `browser:changed` 事件更新 `BrowserPage` 的覆盖层。
网页坐标乘以 tab.zoom 和视口适配比例，光标尺寸不随网页缩放，点击圆环单独锚定真实操作点。
覆盖层不接受指针事件，也不向网页暴露新的 JavaScript 接口。

`e2e/browser-cursor.test.ts` 使用隔离 profile、本地合成网页和模型协议响应，经真实 Agent 工具路径验证
普通点击、网页原生弹窗、导航后滚动、50%/125%/200% 缩放、窄面板、深浅主题交叉组合和减少动态效果。
通过比较光标显示／隐藏的真实窗口截图像素验证实际绘制，另测箭头尺寸与目标坐标误差，避免只断言节点存在。
`e2e/browser-workspace.test.ts` 通过原生输入打开菜单，覆盖检查、框选、书签、DevTools、空白标签、
1200px 与 375px 宽度下的菜单／空状态，并保留页面与全屏切换守卫。测试数据在退出时清理。

### 菜单滚动

斜杠菜单只因键盘导航或检索结果变化主动露出选中项。鼠标悬停只改变选中项，不驱动列表滚动；
滚轮移动列表时，同坐标的鼠标事件不抢回键盘选择。所有 Popover 与斜杠菜单共用菜单滚动样式，

## 回复里的宽表格（2026-09-09）

单元格保持 `nowrap`，宽表格横向滚动。原生滚动条全局关闭，于是溢出不发声：表格在半个词处
截断，看着像表格本来就到那儿为止。现在鼠标停在表格上才浮出应用自己的横向滑块，鼠标离开即隐去。

`Markdown` 的表格分支移入 `MarkdownTable`，拆成不滚动的外框和滚动的内层：滑块和换行按钮钉在
外框上，否则会跟着内容滑走。滑块复用 `OverlayScrollbar`（横向），与编辑器、diff 同一个。

`.ly-scroll-host:hover .ly-hthumb` 是后代选择器，而转录本身就是一个 `ly-scroll-host` —— 鼠标
停在对话任何位置都会点亮屏幕上每张宽表格的下边缘。`scroll.css` 末尾按 `.ly-table` 收窄作用域，
拖动中的滑块单独保住，否则指针离开表格时它会从手底下消失。

换行按钮在表格框内的右上角，但不在滚动区里：它坐在框内顶部一条 26px 的独立条带上，条带用表头
的底色、下面不画分隔线。这条带是「框内右上角」和「不遮挡内容」唯一能同时成立的位置——滚动区
里任何一处钉住的东西，内容都会从它底下滑过去（左边缘处是空的，滚过两百像素就压住
「一键新机后的合理行为」）。条带的高度常驻，否则悬停时表格会往下跳。

图标 `CornerDownLeft`（↵）与 `MoveHorizontal`（↔），各两笔，13px 下不糊；候选六对在真实窗口
里比过。按下后 `data-wrap="true"`，单元格改 `white-space: normal`、最小列宽 6em，表格收到列宽
以内，图标、tooltip 和无障碍标签一并换成「取消换行」，`aria-pressed` 为真。换行是看这一张表的
方式，不跨表格记忆。

`test/ui/markdown-table.test.ts` 覆盖两层结构、按钮不在滚动区内、翻转与复位、窄表格与摘录都不
长出控件。`e2e/table-probe.ts` 在真实窗口量到：溢出 131px；鼠标在对话内但不在表格上时滑块与
按钮 opacity 均为 0，移进表格后为 0.55 和 1，按住滑块 0.85；拖动后 `scrollLeft` 0 → 131；按钮
在框内 3px、距右边框 5px、底边在滚动区顶边之上 2px；tooltip 实际弹出，文本为「自动换行」；
换行后溢出归零、单元格高度 35px → 55px，再按一次完全还原。
